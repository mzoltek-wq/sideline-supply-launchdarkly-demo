    AOV: total after-discount revenue ÷ completed orders. Order conversion: unique buyers ÷ observed shoppers. Cart completion: buyers who started a cart ÷ shoppers who started a cart. These are shopper-level counts, not separate cart sessions. A shopper who started a cart but has no order has not purchased yet; that is not proof of abandonment.

    How to read and reset this view

    Uses actual SDK evaluations from the store. Loading or missing flag data is not counted as “off.” A shopper who sees both values is marked mixed and excluded, along with their orders. Orders made without a valid matching SDK context are excluded too.

    Guest, Maya and Jordan have fixed keys. Use New demo visitor for a fresh anonymous identity. Repeated orders count as separate orders, but a shopper counts once. Earlier receipts created before observation tracking was added are not backfilled.

    Refresh reloads this local view. Another store tab in the same browser updates it automatically. Chrome and the sidebar have separate storage; use the dashboard in the same browser as the store. Reset local demo in the store clears these observations too. It never resets LaunchDarkly analytics.
